# ATS Dashboard

A modern and responsive ATS (Applicant Tracking System) Dashboard built using React.js, Tailwind CSS, and React Router DOM.

This project helps manage:
- Candidates
- Job Listings
- Recruitment Activities
- Candidate Details
- Job Details

---

# 🚀 Features

✅ Responsive Dashboard UI  
✅ Reusable Navbar Component  
✅ Candidate Management  
✅ Job Listings Management  
✅ Candidate Details Page  
✅ Job Details Page  
✅ Dynamic Routing  
✅ Search Functionality  
✅ Responsive Design (320px → 2500px)  
✅ Modern Tailwind CSS UI  
✅ Interactive Dashboard Cards  
✅ Professional Admin Panel Layout  

---

# 🛠️ Tech Stack

- React.js
- Tailwind CSS
- React Router DOM
- React Icons
- Vite
